# La-Nana-Gourmet
Página web desarrollada para un servicio de catering - un servicio de alimentos para eventos.  
# Tecnologías utilizadas  
- HTML
- CSS
- JavaScript  ## Características
- Diseño interactivo
- Galería de imágenes
- Información sobre los servicios
- Navegación entre páginas
- Adaptación para dispositivos móviles
